# 🎓 Monitoria - UFC Quixadá 🧪

Bem-vindo ao meu repositório de monitoria! Aqui organizo todos os materiais, códigos, listas de exercícios e resoluções que desenvolvo durante minha jornada como monitor na **Universidade Federal do Ceará (UFC) - Campus Quixadá**.

O objetivo deste espaço é centralizar o conhecimento e facilitar o acesso dos alunos aos conteúdos das disciplinas que acompanho.
